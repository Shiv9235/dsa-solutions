# Data Structures & Algorithms

A personal collection of C and C++ solutions built through consistent problem-solving practice.

## Structure

| Directory | Covers |
| --- | --- |
| `Arrays/` | Array fundamentals, matrices, two pointers, and sorting/searching |
| `Binary_Search/` | Binary-search patterns and answer-space search |
| `Bit_Manipulation/` | Bitwise operations and related problems |
| `Dynamic_Programming/` | Dynamic-programming problems |
| `Greedy/` | Greedy algorithms and scheduling |
| `Linked_List/` | Singly and doubly linked-list problems |
| `Math/` | Number theory, maths, and basic C/C++ practice |
| `Queues/` | Queue implementations and transformations |
| `Stacks/` | Stack patterns, monotonic stacks, and expressions |
| `Strings/` | String manipulation and parenthesis problems |
| `Trees/` | Binary-tree traversals and tree algorithms |
| `Utilities/` | Small helper/practice programs |

## Run a solution

Compile a C++ solution from the repository root:

```bash
mkdir -p build
g++ -std=c++17 -Wall -Wextra Arrays/1_twoSum.cpp -o build/two_sum
./build/two_sum
```

`build/` and other generated executables are intentionally not tracked. Some files are standalone learning exercises, so their input/output format may differ by problem.

## Notes

- Problem-number prefixes generally correspond to the source platform's problem ID.
- Original source filenames have been retained to preserve the history of the practice work.
- Generated programs previously stored in `output/` are ignored; only source code is intended for version control.
